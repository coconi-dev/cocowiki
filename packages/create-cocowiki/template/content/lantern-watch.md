# 巡灯会

巡灯会照管 [[雾港]] 沿岸的灯塔，成员被当地人称为“守灯人”。他们维护灯具、记录能见度，并在起雾时向船只传递信号。

## 旧版值守安排

过去采用日班与夜班交接：日班检修灯具，夜班观察航道。此安排已停用，保留于此仅供了解组织沿革。
